# UX, SEO & GEO

## UX
- Alle Seiten folgen UX Best Practices: klare Hierarchie, konsistente Navigation, eindeutige CTAs
- Mobile First – alle Layouts zuerst für mobile Geräte entwerfen
- Keine ablenkenden Animationen, kein Auto-Play
- Ladezeiten und Interaktionen müssen sich schnell anfühlen (Feedback bei Aktionen)

## SEO
- Jede Seite hat eine einzigartige, aussagekräftige `<title>` und `<meta description>`
- Saubere URL-Struktur, keine Parameter-URLs
- Alle Bilder haben beschreibende `alt`-Attribute
- Strukturierte Daten (Schema.org) für LocalBusiness, Öffnungszeiten, Kontakt
- Canonical-Tags auf jeder Seite
- Interne Verlinkung bewusst einsetzen
- WordPress-Generator-Tag und andere Tech-Hinweise aus dem HTML entfernen

## GEO (Generative Engine Optimization)
- Inhalte klar, direkt und faktisch formulieren – geeignet für KI-Zusammenfassungen
- Fragen-Antwort-Struktur wo sinnvoll (FAQ-Abschnitte)
- Firmenname, Adresse, Leistungen und USPs explizit und konsistent auf jeder relevanten Seite nennen
- Strukturierte Daten vollständig und korrekt pflegen
- Keine Inhalte hinter JavaScript verstecken
